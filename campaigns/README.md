# Westwild: Starter Campaigns

Two starter campaigns for Westwild, written by Anthony "Othello" Merriweather. Free for noncommercial use under the Westwild license (see LICENSE.md). Commercial use needs a license: see COMMERCIAL_LICENSE.md.

Play them in order:
1. **Handsome Jack the Duelist of Saint Levoir** (One-shot starter, 3 parts): folder `1_Handsome_Jack_the_Duelist/`
2. **Get 'Em To The Buntline** (Story campaign, 4 parts): folder `2_Get_Em_To_The_Buntline/`

## How to load a campaign
Each campaign folder holds a `*_LOAD_THIS.zip`. Westwild loads that zip **as it is**. Do not unzip it.

1. Open Westwild and go to **The World** (the viewer screen the whole table can see).
2. Under the command bar, press **Choose Campaign Zip** and pick the `*_LOAD_THIS.zip` file from the campaign folder you want.
3. Press **Launch Campaign**. The log prints "Campaign loaded from zip" and the campaign's introduction.
4. Both campaigns start at **Buntline Trade Road**, so no travel is needed. Type `/quest` to start the first part.
5. When a part says so, type `/ccstart` to play the cutscene. If the table wants to skip it, type `/ccend`.
6. When a part ends, follow the written next step exactly. Use `/locations` to see where you can travel and `/look` to read the room again.

Useful commands: `/travel LOCATION`, `/locations`, `/look`, `/quest`, `/ccstart`, `/ccend`, `/clear`, `/reset`.

## If it will not load
- Make sure you chose the inner `*_LOAD_THIS.zip`, not this pack's outer zip.
- Everything runs in your browser; nothing is uploaded anywhere. If a load fails, the World log prints the reason ("Campaign loading failed: ...").
- Send problems to support@wordblocklabs.com with the subject "Westwild bug report".

## About these campaigns
Both were written for the Westwild alpha and tuned to teach the game: moving, running quests, clue gathering, cutscenes and a final confrontation. A campaign builder is still in development and is not part of this release.
